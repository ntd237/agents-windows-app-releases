# Agents Windows Releases

Public distribution channel for the private [agents-windows-app](https://github.com/ntd237/agents-windows-app) repository: installers, update signatures and update manifests are published here automatically by CI.

## Download

Get the latest installer from the [latest release](https://github.com/ntd237/agents-windows-app-releases/releases/latest).

The source code stays private; this repository only holds release assets (NSIS installer, minisign `.sig` files and `latest.json` for the in-app updater).
